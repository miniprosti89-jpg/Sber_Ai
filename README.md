# 🩺 SberMedAI Backend (ИИ-помощник пациента)

Бэкенд-часть прототипа интеллектуальной медицинской системы. Сервер написан на **FastAPI** и отвечает за маршрутизацию, обработку запросов и предоставление статических файлов для бесшовного клиентского интерфейса (сбор анамнеза, электронная регистратура и план лечения).

---

## 🚀 Основной стек
* **Python 3.10+**
* **FastAPI** — современный, быстрый веб-фреймворк для создания API.
* **Uvicorn** — молниеносный ASGI-сервер для запуска приложения.

---

## 📂 Структура проекта
```text
Sber_Ai/
├── server.py              # Главный файл бэкенда (FastAPI приложение)
├── requirements.txt       # Список зависимостей Python
└── frontend/              # Клиентская часть (HTML, CSS, JS)
    ├── templates/
    │   └── index.html     # Главная страница интерфейса
    └── static/
        ├── css/
        │   └── style.css  # Стили интерфейса и вкладок
        └── js/
            └── app.js     # Логика переключения режимов и динамики

```

## 🛠️ Инструкция по запуску

### Шаг 1. Клонирование репозитория

```bash
git clone <ссылка_на_ваш_репозиторий>
cd Sber_Ai

```

### Шаг 2. Установка зависимостей

* **Для Linux (Arch Linux / Ubuntu и др.):**
Если система блокирует глобальную установку через pip (PEP 668), используйте виртуальное окружение или пакетный менеджер системы:
```bash
# Пример для Arch Linux:
sudo pacman -S python-fastapi uvicorn

# Либо через виртуальное окружение:
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

```


* **Для Windows:**
```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

```



### Шаг 3. Запуск сервера

Убедитесь, что вы находитесь в корневой папке проекта (`Sber_Ai`), где лежит файл `server.py`, и выполните:

```bash
uvicorn server:app --reload

```

*(Флаг `--reload` автоматически перезапускает сервер при изменении кода).*

### Шаг 4. Открытие в браузере

После успешного запуска перейдите по адресу:
👉 **`http://127.0.0.1:8000`**
