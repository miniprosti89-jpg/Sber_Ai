# Инструкция по развертыванию и запуску проекта

### 1. Клонирование репозитория

Открой терминал и клонируй проект на новом устройстве:

```bash
git clone <ссылка_на_ваш_репозиторий>
cd Sber_Ai

```

### 2. Установка зависимостей (для Arch Linux)

Проект использует FastAPI для бэкенда и Uvicorn как ASGI-сервер. Установи их через пакетный менеджер `pacman` (предварительно обновив базы данных):

```bash
sudo pacman -Sy
sudo pacman -S python-fastapi uvicorn

```

*(Если используется Ubuntu / Debian / macOS, вместо этого можно использовать стандартную команду через виртуальное окружение: `python3 -m venv venv && ./venv/bin/pip install fastapi uvicorn`)*.

### 3. Проверка структуры проекта

Убедись, что файлы находятся на своих местах в соответствии с архитектурой:

* Корневой файл бэкенда: `server.py` (должен лежать прямо в корне проекта).
* Фронтенд: папка `frontend/` со структурой `frontend/templates/index.html`, `frontend/static/css/style.css` и `frontend/static/js/app.js`.

### 4. Запуск сервера

Находясь в корневой папке проекта (`Sber_Ai`), запусти сервер разработки Uvicorn:

```bash
uvicorn server:app --reload

```

### 5. Проверка работоспособности

Открой браузер и перейди по адресу:
👉 **`[http://127.0.0.1:8000](http://127.0.0.1:8000)`**

Интерфейс ИИ-помощника пациента загрузится, и можно будет тестировать переключение сценариев (сбор анамнеза, запись к врачу, управление лекарствами).
